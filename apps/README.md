# APPS — Mapa de módulos

Diretórios reservados para implementação futura. **Nenhum código está presente.**

| Módulo | Responsabilidade |
|---|---|
| [consumer-web](consumer-web/) | Experiência de consulta de URLs para consumidores. Consulta simples; risco, confiança e cobertura; orientações preventivas. |
| [analyst-web](analyst-web/) | Workbench de investigação técnica e atribuição. Grafo, hipóteses, evidências, timeline, revisão, dossiês. |
| [enterprise-web](enterprise-web/) | Console corporativo de proteção de marcas. Portfólio de marcas, alertas, filas e integrações. |
| [admin-portal](admin-portal/) | Painel administrativo interno. Tenants, políticas, auditoria, segurança e fontes. |
